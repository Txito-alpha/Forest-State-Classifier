Clustering and maximum likelihood classification are reimplemented in numpy, so no GRASS GIS installation or external process is required. Includes an interactive class labelling dialog with a Red-NIR scatter plot, raster attribute table output, signature reuse across years, and per-subcompartment aggregation.
