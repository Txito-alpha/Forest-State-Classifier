about=Implements the workflow of "Forest condition mapping using satellite imagery" (Hokkaido Research Organization, Forestry Research Institute, 2025) as a single plugin. Clustering and maximum likelihood classification are reimplemented in numpy, so no GRASS GIS installation or external process is required. Includes an interactive class labelling dialog with a Red-NIR scatter plot, raster attribute table output, signature reuse across years, per-subcompartment aggregation, and batch input from a folder (recursive search) as a mosaic or file by file.

changelog=0.2.2
    - Added: 意味づけ画面に「適用」ボタンを追加。画面を閉じずに、レイヤの色・凡例、ラスタ属性テーブル、シグネチャへ変更を反映できる。OK は「適用して閉じる」、キャンセルは未適用の変更を破棄して閉じる（未適用の変更があれば確認する）。
    - Changed: 意味づけ画面を非モーダルにし、開いたまま地図を拡大・移動して確認できるようにした。分類結果は意味づけ画面を開く前に地図へ追加する。
    0.2.1
    - Added: フォルダ入力で、出力先に同名の分類結果（<名前>_class.tif）が既にある場合の扱いを選べるようにした。「スキップする」（既定）「上書きする」「別名で保存する（_2 を付ける）」の3種類で、GUI とプロセシングの両方に追加。スキップを使うと、途中で止まった一括処理を続きから流し直せる。
    0.2.0
    - Added: 入力モードを追加。「単一ファイル」と「フォルダ（再帰検索）」を切り替えられるようにした。単一ファイルではプロジェクトに読み込んでいないファイルも直接指定できる。
    - Added: フォルダ入力では、パターン（*.tif;*.vrt など）に合うラスタをサブフォルダまで検索し、一覧で処理対象を選べる。出力フォルダ内と本プラグインの出力（*_class.tif など）は自動的に除外する。
    - Added: フォルダ入力の処理方法として「モザイク（VRT にまとめて 1 回分類）」と「ファイルごと（ファイル単位で分類結果を出力）」を選択可能にした。ファイルごとでは、全ファイル共通のクラス定義（全ファイルから標本を集めて 1 回クラスタリング）と、入力フォルダ構成の再現を選べる。
    - Added: プロセシングアルゴリズム「教師なし分類」にも入力モード・入力フォルダ・再帰検索・パターンなどのパラメータを追加。
    - Changed: GUI とプロセシングの実行部を core/pipeline.py に共通化した。
    0.1.12
    - Fixed: 同じ id のプロセシングプロバイダが既に登録されている場合に、アンロード時「RuntimeError: wrapped C/C++ object of type RinkyoProvider has been deleted」が出る問題を修正。
    0.1.11
    - Fixed: RATがclass 1～のままの場合にラベル別集計が0になる問題を修正。分類ラスタに対応する_signature.jsonのlabelsを優先し、RATをフォールバックとして使用する。
    0.1.10
    - Fixed: 小班別集計で標準林況ラベルの集計列が出力されない問題を修正。RAT内の該当画素が0件の場合も、常緑針葉樹林_画素数・ha・率などの列を必ず出力する。
    0.1.9
    - Added: 小班別集計の出力形式として GeoPackage（.gpkg）と Excel ブック（.xlsx）を選択可能にした。XLSX は属性・集計値のみ、GPKG は形状を含めて出力する。
    0.1.8

    0.1.7
